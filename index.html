一、项目概述

本项目旨在开发一套 纯语音 AI 面试官系统，替代传统初筛面试环节。HR 只需上传候选人简历，系统即可自动生成个性化面试题，通过真人般的语音交互完成面试，并输出结构化评估报告。

核心价值：大幅降低 HR 初筛工作量，统一面试标准，提升候选人体验，单场面试成本约 0.76 ~ 1.64 元，为真人面试成本的 1/100。
✓ 全部为国内服务商：无需翻墙、无需国际信用卡、无需科学上网，公司内网直接调用。

八、Token 消耗详解（给领导看的算账依据）

领导如果问"为什么 LLM 要花 0.69 元"，以下就是每一笔 Token 的来龙去脉。

1. 系统 Prompt（每轮都发）
内容："你是一位资深 Java 面试官..." + 岗位 JD（约 800 字）+ 候选人简历（约 1500 字）
约 3,000 tokens × 12 轮 = 36,000 tokens
2. 历史对话累积（上下文）
第 1 轮：无历史
第 2 轮：带上第 1 轮对话 (~600 tokens)
第 3 轮：带上前 2 轮 (~1,200 tokens)
...
累积约 8,000 tokens
3. 用户输入（候选人语音转文字）
候选人 15 分钟说话，约 3,000-5,000 字
合计约 4,000 tokens
4. AI 输出（面试官回复+评分）
每轮回复约 300-400 字（含追问 + 简短评价）
12 轮 × 400 = 4,800 tokens
Input 总计：36,000 + 8,000 + 4,000 = 48,000 tokens ≈ 按 20,000 计费（Prompt Caching 命中后，历史重复部分降价 50%）

Output 总计：4,800 tokens

通义千问 2.5-Max: 20 × ¥0.02 + 4.8 × ¥0.06 = ¥0.40 + ¥0.29 = ¥0.69
DeepSeek V3: 20 × ¥0.002 + 4.8 × ¥0.008 = ¥0.04 + ¥0.038 = ¥0.08

十一、AI 怎么判断追问 / 换题 / 结束？

不是固定题序，而是根据回答动态决定（由 LLM Prompt 控制）：

候选人表现AI 行为示例
回答很好，有细节 追问（深挖一层） "你刚才说的方案，如果 QPS 到 10 万还能用吗？"
回答一般，没什么亮点 下一题 "好的，我们来看下一个问题..."
完全不会 / 胡说 再试一题 "没关系，换个角度，你知道布隆过滤器吗？"
连续 2-3 题都不会 结束面试 "今天的面试就到这里，感谢你的时间。"

兜底规则：至少问满 3 题（防止上来就结束），最多问 8 题，总时长超 30 分钟强制结束。
