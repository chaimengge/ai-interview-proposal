四、Token 消耗详解（给领导看的算账依据）

领导如果问"为什么 LLM 要花 0.69 元"，以下就是每一笔 Token 的来龙去脉。

1. 系统 Prompt（每轮都发）
内容："你是一位资深 Java 面试官..." + 岗位 JD（约 800 字）+ 候选人简历（约 1500 字）
约 3,000 tokens × 12 轮 = 36,000 tokens
2. 历史对话累积（上下文）
第 1 轮：无历史
第 2 轮：带上第 1 轮对话 (~600 tokens)
第 3 轮：带上前 2 轮 (~1,200 tokens)
...
累积约 8,000 tokens
3. 用户输入（候选人语音转文字）
候选人 15 分钟说话，约 3,000-5,000 字
合计约 4,000 tokens
4. AI 输出（面试官回复+评分）
每轮回复约 300-400 字（含追问 + 简短评价）
12 轮 × 400 = 4,800 tokens
Input 总计：36,000 + 8,000 + 4,000 = 48,000 tokens ≈ 按 20,000 计费（Prompt Caching 命中后，历史重复部分降价 50%）

Output 总计：4,800 tokens

通义千问 2.5-Max: 20 × ¥0.02 + 4.8 × ¥0.06 = ¥0.40 + ¥0.29 = ¥0.69
DeepSeek V3: 20 × ¥0.002 + 4.8 × ¥0.008 = ¥0.04 + ¥0.038 = ¥0.08
